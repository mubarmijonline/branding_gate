# 20. Image attachments open in a viewer

on the page, not a new tab.

thumbnail opens the viewer with its name and "1 / 2"; the arrow shows the next
file; Esc closes it; no new tab opens. The same from the receipts pop-up of a
staff expense, where Esc closes only the viewer. PDFs still open in a new tab.
