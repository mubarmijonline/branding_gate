COPILOT & VS CODE PERFORMANCE FIX - COMPLETE GUIDE
================================================================================

PROBLEM SUMMARY:
1. Copilot was hanging VS Code due to indexing too many files
2. Copilot was recreating deleted .sql and .md files (this should NOT happen)
3. VS Code was slow due to file watching overhead

SOLUTIONS APPLIED:
================================================================================

1. UPDATED .copilotignore
   - Added explicit rules to NEVER index *.sql and *.md files
   - Excluded branding_gate_VENV/ (virtual environment - huge)
   - Excluded static/ directory (vendor libraries)
   - Excluded templates/ (HTML files)
   - Excluded uploads/ (user data)

2. UPDATED .vscode/settings.json
   - Disabled Copilot for markdown and SQL files
   - Reduced context length from 500 to 300
   - Reduced suggestion counts for better performance
   - Added aggressive file watching exclusions
   - Disabled Python indexing (huge performance gain)
   - Disabled minimap, breadcrumbs, and code lens
   - Disabled Git decorations and auto-refresh

3. UPDATED .gitignore
   - Added comprehensive exclusion patterns
   - Organized by category for clarity

================================================================================
IMPORTANT: HOW TO STOP FILE RECREATION
================================================================================

IF COPILOT KEEPS RECREATING DELETED FILES:

Option 1: COMPLETELY RELOAD VS CODE
   1. Close ALL VS Code windows
   2. Kill any lingering VS Code processes:
      pkill -9 code
   3. Clear VS Code cache:
      rm -rf ~/.config/Code/Cache/*
      rm -rf ~/.config/Code/CachedData/*
   4. Reopen VS Code
   5. Wait for indexing to complete (watch bottom status bar)

Option 2: DISABLE COPILOT TEMPORARILY
   1. Press Ctrl+Shift+P
   2. Type: "GitHub Copilot: Disable"
   3. Delete the unwanted files
   4. Re-enable: "GitHub Copilot: Enable"

Option 3: MOVE FILES TO BACKUP (SAFEST)
   Instead of deleting, move them:
   mkdir ~/copilot_backup
   mv *.sql *.md ~/copilot_backup/
   
   This way Copilot can't recreate them, and you still have backups.

================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Copilot still recreates files
SOLUTION: 
   1. pkill -9 code
   2. rm -rf ~/.config/Code/Cache/*
   3. Restart VS Code
   4. Wait 5 minutes for full reindexing
   5. Check if files are recreated - if yes, contact GitHub Copilot support

PROBLEM: VS Code still hangs
SOLUTION:
   1. Check CPU usage: htop
   2. Look for "code" or "python" processes using >80% CPU
   3. If Python: Disable Python indexing completely
      "python.analysis.indexing": false
   4. If Copilot: Reduce context length to 100
      "github.copilot.advanced.length": 100

PROBLEM: Lost Copilot suggestions quality
SOLUTION:
   - Increase context length gradually (200 -> 300 -> 400)
   - Re-enable markdown/SQL if needed for specific files
   - Use Copilot Chat instead of inline suggestions
