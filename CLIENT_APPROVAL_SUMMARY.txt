                    CLIENT APPROVAL SYSTEM - SUMMARY
═══════════════════════════════════════════════════════════════════════════

📦 FEATURE OVERVIEW
───────────────────────────────────────────────────────────────────────────
A complete client approval workflow for individual items after pricing.
Sales/Admin can submit priced items to clients and track approval status.

1️⃣  DATABASE CHANGES
───────────────────────────────────────────────────────────────────────────
File: add_client_approval_system.sql

New Columns in sales_request_items:
  • approval_status (pending/submitted/approved/rejected)
  • submitted_for_approval_date (timestamp)
  • submitted_by (user ID)
  • client_approval_date (timestamp)
  • client_feedback (text)

New Table: item_client_approval_log
  Tracks complete approval history:
  • action_type (submitted/approved/rejected/resubmitted)
  • action_by (user)
  • previous_status → new_status
  • notes and pricing snapshot
  • timestamps for audit trail

3️⃣  BACKEND API ENDPOINTS
───────────────────────────────────────────────────────────────────────────
File: branding_gate.py (Lines ~9155-9620)

Route                                          Method  Purpose
────────────────────────────────────────────────────────────────────────
/client_approval                               GET     Render page
/api/client-approval/items                     GET     Get items (filtered)
/api/client-approval/statistics                GET     Get counts
/api/client-approval/items/<id>                GET     Get item details
/api/client-approval/items/<id>/submit         POST    Submit for approval
/api/client-approval/items/<id>/history        GET     Get approval timeline
/api/client-approval/items/<id>/approve        POST    Approve item
/api/client-approval/items/<id>/reject         POST    Reject item

All endpoints:
  ✓ Require authentication (session check)
  ✓ Require 'sales' or 'admin' role
  ✓ Use optimized connection pattern
  ✓ Log all changes via log_item_change()
  ✓ Return JSON responses

                             WORKFLOW DIAGRAM
═══════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────┐
│ STAGE 1: ITEM CREATION                                              │
│ Sales creates request → Items created with approval_status='pending'│
│ cost_per_item = NULL, sell_per_item = NULL                          │
└─────────────────────────┬───────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────────────┐
│ STAGE 2: PRICING                                                    │
│ Sales/Admin sets:                                                   │
│   • cost_per_item (operations cost)                                 │
│   • sell_per_item (client price)                                    │
│ Status: Still 'pending' but shows as "Ready to Submit"              │
└─────────────────────────┬───────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────────────────┐
│ STAGE 3: SUBMISSION                                                 │
│ Sales clicks "Submit for Approval":                                 │
│   • approval_status → 'submitted'                                   │
│   • submitted_for_approval_date → NOW()                             │
│   • submitted_by → current user ID                                  │
│   • Logs in item_client_approval_log                                │
│   • (Future) Sends notification to client                           │
└─────────────────────────┬───────────────────────────────────────────┘
                          │
                          ▼
              ┌───────────┴───────────┐
              │                       │
              ▼                       ▼
    ┌──────────────────┐    ┌──────────────────┐
    │ STAGE 4A: APPROVE│    │ STAGE 4B: REJECT │
    │ Client approves  │    │ Client rejects   │
    │ Status→'approved'│    │ Status→'rejected'│
    │ Sets feedback    │    │ Sets feedback    │
    │ Sets approval    │    │ Sets approval    │
    │ date             │    │ date             │
    └──────────────────┘    └─────┬────────────┘
                                  │
                                  ▼
                        ┌──────────────────────┐
                        │ STAGE 5: RESUBMISSION│
                        │ Sales adjusts pricing│
                        │ Resubmits item       │
                        │ Back to Stage 3      │
                        └──────────────────────┘
